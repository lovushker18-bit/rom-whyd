# ROM — Vercel + Neon + Gmail

Сайт размещается на Vercel, база данных Neon Postgres, подтверждение почты — через Gmail SMTP и шестизначный код. Supabase и Resend не нужны.

## Обновление
1. Замените файлы проекта в GitHub содержимым этой папки `rom-site`.
2. В Vercel → Project → Settings → Environment Variables добавьте:
   - `DATABASE_URL` — строка подключения Neon (уже настроена, не меняйте).
   - `GMAIL_USER` — адрес отдельного Gmail-аккаунта для писем.
   - `GMAIL_APP_PASSWORD` — **пароль приложения Google**, НЕ обычный пароль аккаунта. Включите двухэтапную аутентификацию и создайте пароль приложения в настройках Google Account → Security → App passwords. Уберите пробелы при вставке.
3. Для `GMAIL_APP_PASSWORD` выберите тип Secret. Все переменные должны быть доступны в Production.
4. В Vercel → Deployments выполните Redeploy последней версии после сохранения переменных.
5. Войдите в ROM, откройте «Аккаунт» или «Настройки», нажмите «Отправить код», затем введите шестизначный код в форму.

## Важно
- Не требуется повторно выполнять `db/postgres.sql`, если таблицы уже созданы. Новых таблиц нет: используется существующая `email_tokens`.
- Удалите неиспользуемые `RESEND_API_KEY`, `EMAIL_FROM`, `PUBLIC_URL` из Vercel, когда убедитесь, что новая версия работает.
- Gmail SMTP — простой вариант для небольшого проекта, но Google может ограничивать автоматические отправки или блокировать подозрительную активность. Для массовой регистрации понадобится специализированная почтовая служба.
- Код действует 10 минут. Повторный запрос ограничен примерно одной минутой.
- Новые аккаунты могут входить до подтверждения, но сервер запрещает им оценки и рецензии.
- Никогда не публикуйте `DATABASE_URL` и `GMAIL_APP_PASSWORD` в GitHub.
